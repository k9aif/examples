## What this project is

A demo for IBM: their Process Studio (Context Studio / Process Studio / Agent Studio suite,
Federal-bound) generates detailed process blueprints (`.md`) and BPMN diagrams (`.bpmn`) with
GREEN/AMBER/RED autonomy-zone coding baked in. This project makes that output the *input* to a
K9-AIF studio, which generates a working multi-agent implementation from it — and, critically,
produces a **Process-to-Implementation Traceability Matrix** proving each process element landed
correctly in the generated code. See `plan.md` → "Primary deliverable" for the full spec.

## Key example data (validation case, not the target)

`process_studio_generated_files/` — a real Process Studio export (Accounts Payable & Expense
Reimbursements, APQC PCF 9.5): `.bpmn`, `.md` blueprint, `.docx`/`.html` renderings, eval plan
(`.md`/`.csv`), and an eval-trace (`.json`). See `plan.md` for the full artifact inventory and
what each one maps to.

**Important:** `studiox_v2` is a generic studio for *any* BPMN/process-output document in *any*
domain. This AP-invoice example validates the work; nothing should be built or judged as "done"
against this one file alone. See `plan.md` → "Design principle."

`studio-generated-output/` — a real scaffold generated by the (current, unfixed) studio from the
AP invoice BPMN. Used to find the bugs logged in `plan.md` → "Known Bugs."
