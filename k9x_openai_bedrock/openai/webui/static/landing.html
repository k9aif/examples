OpenAI Agents SDK

Runs the agent

A well-made library for agent loops. From its documentation:

  • Agent loop calls the model, runs tools, repeats until done
  • Handoffs one agent delegates to a specialist
  • Guardrails on input, output and tools, per application
  • Approvals pause a run for a decision, then resume
  • Tracing every run, with pluggable processors
  • Any compatible model OpenAI's, or an OpenAI-compatible endpoint
+
K9-AIF Framework · K9X Ecosystem

Governs every step

One configuration that holds for every agent on every runtime:

  • k9x Shield on the request, each tool call and result, every reply
  • Zero Trust for the caller and for each agent that takes a turn
  • K9 Model Router picks each model, eligibility first
  • Agents in K9-AIF YAML declared, not coded; unknown tools fail at start-up
  • Sole broker the adapter builds every agent and tool itself
  • One layer, every runtime CrewAI, LangGraph, Claude Agent SDK, and now OpenAI

How it works

Four moves, every one checked

The SDK does the work. K9-AIF decides at each crossing.

1
Admit Zero Trust checks the caller's role; Shield screens the request before the SDK starts.
›
2
Run The Runner starts WeatherAgent, built from YAML; Zero Trust checks the agent too.
›
3
Think and act The Model Router picks a tool-calling model; each tool call and result passes Shield.
›
4
Answer Every reply and the final answer pass Shield; you get the answer and its receipt.

Built on the K9-AIF framework

The adapter is one more orchestrator. It extends the same BaseOrchestrator contract as every K9-AIF orchestrator, so the Router sends it work like any other. On this path the SDK's Runner and agent take the place of Squad and Agent, while Shield, Zero Trust and the Model Router stay shared with every other path.

The K9X ecosystem brings the framework to life: K9X SATAN fires attacks at Shield to prove it holds, K9X HIL handles human decisions, K9X Studio builds K9-AIF applications visually, and DAS is a full reference application.
